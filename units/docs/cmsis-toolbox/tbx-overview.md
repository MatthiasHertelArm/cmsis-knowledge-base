The CMSIS-Toolbox is a set of command-line tools for building embedded applications on Arm Cortex-M and Ethos-U based microcontrollers. It supports [multiple compiler toolchains](https://open-cmsis-pack.github.io/cmsis-toolbox/overview/installation.md#compiler-toolchains), uses [YAML project files and software packs](https://open-cmsis-pack.github.io/cmsis-toolbox/overview/build-overview.md#minimal-project-setup) for device support and reusable software components, and integrates with CMake/Ninja for scalable builds from simple applications to complex multi-processor systems.
