Version            | Description
:-----------------:|:-------------------------
2.15.0             | CMSIS-Toolbox [2.15.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.15.0) fixes [several issues](https://github.com/orgs/Open-CMSIS-Pack/projects/22/views/14). It documents a [workaround for stack unwinding issues with GDB debugger](https://open-cmsis-pack.github.io/cmsis-toolbox/Troubleshooting.md#stack-unwinding-fails-or-hangs), and adds [native CMake project integration](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#native-cmake-build-integration), solution-level [`compiler-alias:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#compiler-alias), support for per-library [`whole-archive`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#link), and enhanced pack and configuration [lifecycle management](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#plm-of-software-packs).
2.14.0             | CMSIS-Toolbox [2.14.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.14.0) fixes [several issues](https://github.com/orgs/Open-CMSIS-Pack/projects/22/views/13). It adds [MLOps Integration](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#mlops-integration), target-set-specific [temporary directories](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#output-dirs), automatic rebase of [configuration files](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#plm-of-configuration-files), enhanced [library generation](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#generate-library) with [component](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#components) `build-scope:`, and a command to [check for pack updates](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#plm-of-software-packs).
2.13.0             | CMSIS-Toolbox [2.13.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.13.0) fixes [several issues](https://github.com/orgs/Open-CMSIS-Pack/projects/12/views/12) and adds [compiler support](https://open-cmsis-pack.github.io/cmsis-toolbox/installation.md#compiler-toolchains) for Microchip XC and CLANG_TI. The pyOCD command `run` supports [SEGGER RTT](https://open-cmsis-pack.github.io/cmsis-toolbox/pyOCD-Debugger.md#rtt). A [minimal setup](https://open-cmsis-pack.github.io/cmsis-toolbox/pyOCD-Debugger.md#minimal-setup) for pyOCD is documented.
2.12.0             | CMSIS-Toolbox [2.12.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.12.0) fixes [several issues](https://github.com/orgs/Open-CMSIS-Pack/projects/22/views/9). The new [West Build System Integration](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#west-build-system-integration) manages Zephyr applications in context with a csolution project.
2.11.0             | CMSIS-Toolbox [2.11.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.11.0). For a [`image:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#images) the [`device:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#device) node can be used to specify a processor `pname`. [`csolution`](https://open-cmsis-pack.github.io/cmsis-toolbox/build-tools.md#csolution-invocation) adds commands that list debuggers, examples, and templates. The files [`cbuild.yml`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-CBuild-Format.md) and [`cbuild-run.yml`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-CBuild-Format.md) are now located in `out` directory.
2.10.0             | CMSIS-Toolbox [2.10.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.10.0). Extends [`load:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#load) to `project-context:`, adds a [server mode](https://open-cmsis-pack.github.io/cmsis-toolbox/Experimental-Features.md#server-mode) and corrects [several issues](https://github.com/orgs/Open-CMSIS-Pack/projects/22/views/7) such as ST-Link debug adapter selection and CubeMX support.
2.9.0              | CMSIS-Toolbox [2.9.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.9.0). Added the input nodes [`link-time-optimize:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#link-time-optimize) and [`target-set:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#target-set) to configure application scope and [`debugger:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#debugger). The [`images:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#images) node (previously `load:`) adds ELF files generated with other systems. The [Run and Debug Configuration](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#run-and-debug-configuration) using the [`cbuild-run.yml`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-CBuild-Format.md#run-and-debug-management) file is extended for multi-core systems and a range of supported [Debug Adapters](https://open-cmsis-pack.github.io/cmsis-toolbox/build-operation.md#debug-adapter-integration). See here for [more details](https://github.com/orgs/Open-CMSIS-Pack/projects/19).
2.8.0              | CMSIS-Toolbox [2.8.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.8.0). New YML input nodes to add [`memory:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#memory), configure [`debugger:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#debugger), and [`load:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#images) to add image files. The [`*.cbuild-run.yml`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-CBuild-Format.md#run-and-debug-management) file contains run and debug information for a target. See here for [more details](https://github.com/orgs/Open-CMSIS-Pack/projects/17).
2.7.0              | CMSIS-Toolbox [2.7.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.7.0). Adds [C++ language](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#language-cpp): `c++23`, `gnu++23`; [output](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#output) linker MAP file control; [MCUXpresso Config Tool](https://open-cmsis-pack.github.io/cmsis-toolbox/MCUXpressoConfig.md); [experimental features](https://open-cmsis-pack.github.io/cmsis-toolbox/Experimental-Features.md) for multi-project linker scripts, debug, and run. Fixed: `components:` now require [Csub](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#component-name-conventions) specifier; LLVM/Clang 19 compatibility; handling of [group options](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#groups). See here for [more details](https://github.com/orgs/Open-CMSIS-Pack/projects/14).
2.6.0              | CMSIS-Toolbox [2.6.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.6.0); extends [pack:](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#pack-name-conventions) version specifier and [C language](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#language-c) support to C17 and C23. Improved is [regions header file generation](https://open-cmsis-pack.github.io/cmsis-toolbox/CreateApplications.md#regions-header-file) for linker scripts. It adds [trustzone: secure-only](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#processor) for projects without secure entries, [apis](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-CBuild-Format.md#apis), [messages](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-CBuild-Format.md#cbuilds), and [PLM status for config files](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-CBuild-Format.md#files-of-a-component) to cbuild.yml information, and fixes several minor issues. It is no longer possible to specify [compiler](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#compiler) in the [`cdefault.yml`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#cdefault) file.  See here for [more details](https://github.com/orgs/Open-CMSIS-Pack/projects/13).
2.5.0              | CMSIS-Toolbox [2.5.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.5.0); direct CMake interface is now default, [`tmpdir:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#output-dirs) controls location of interim files, adds [`add-path-asm:`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#add-path-asm), adds [`define-asm`](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#define-asm), adds [regular expression](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#regular-expressions) search to `for-context:`/`not-for-context`, and contains several corrections.
2.4.0              | CMSIS-Toolbox [2.4.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.4.0); adds [CubeMX integration](https://open-cmsis-pack.github.io/cmsis-toolbox/CubeMX.md), [pre/post-build steps](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#prepost-build-steps), simplifies the [generator integration](https://open-cmsis-pack.github.io/cmsis-toolbox/build-operation.md#generator-integration), and contains several corrections.
2.3.0              | CMSIS-Toolbox [2.3.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.3.0) adds in the csolution project files [component instances](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#instances) and [optimize: debug](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#optimize). Tools are extended with [cbuild setup command](https://open-cmsis-pack.github.io/cmsis-toolbox/build-operation.md#details-of-the-setup-mode), [--frozen-pack option](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#reproducible-builds). Refer to [release information](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.3.0) for more details.
2.2.0              | CMSIS-Toolbox [2.2.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.2.0) adds [generator integration](https://open-cmsis-pack.github.io/cmsis-toolbox/build-operation.md#generator-integration), extends [translation controls](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-Input-Format.md#translation-control), adds the legacy [context set](https://open-cmsis-pack.github.io/cmsis-toolbox/build-tools.md#legacy-context-set), adds [pack locking](https://open-cmsis-pack.github.io/cmsis-toolbox/YML-CBuild-Format.md#lock-pack-versions), and improves [linker script management](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview.md#linker-script-management). Refer to [release information](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.2.0) for more details.
2.0.0              | Initial release for CMSIS-Toolbox [2.0.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases/tag/2.0.0)
