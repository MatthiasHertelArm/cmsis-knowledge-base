_Part of: Directory Structure_

By default, the following output directories and build information files are generated using the [`cbuild`](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview/build-tools.md#build-a-project) command.

Output                                        | Content
:---------------------------------------------|:---------------
`./out/<project>/<target>/<build>`            | Contains the final binary and symbol files of a project context.
`./out/<project>/<target>/<build>/<project>.<build>+<target>.cbuild.yml` | [Build description](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview/YML-CBuild-Format.md#cbuildyml) generated for a project context.
`./out/<project>/<target>/<build>/compile_commands.json` | Compilation database generated by `cbuild setup` for [Static Code Analysis](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview/build-tools.md#static-code-analysis).
`./out/<project>/<target>/<build>/compile_macros.h` | Compiler built-in macros referenced by the [compilation database](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview/build-tools.md#static-code-analysis).
`./out/<solution>+<target>.cbuild-run.yml`     | [Programming and debugging description](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview/YML-CBuild-Format.md#run-and-debug-management) generated for the active target-set.

The actual directories are controlled by [`output-dirs:`](https://open-cmsis-pack.github.io/cmsis-toolbox/build-overview/YML-Input-Format.md#output-dirs). Tools should resolve these files through the references in `<solution>.cbuild-idx.yml` instead of constructing their paths.
