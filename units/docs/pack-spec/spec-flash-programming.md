**Flash Programming Algorithms** are a piece of software to erase or download applications to Flash devices. A device
family pack (DFP) usually contains predefined Flash algorithms for programming the devices that are supported within. A
template for creating new algorithms are available in the **ARM:CMSIS** Pack. The following section describes the process
in more detail.
