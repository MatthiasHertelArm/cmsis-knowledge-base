This is a list of the relevant files and directories.

| File or directory | Description |
|---|---|
| [`source`](https://github.com/ARM-software/CMSIS-Ethos-U/blob/cf13d8d/./source/) | Core-driver source, public headers, single- and multi-variant NPU support, CMake build files, and Zephyr module metadata. |
| [`interface`](https://github.com/ARM-software/CMSIS-Ethos-U/blob/cf13d8d/./interface/) | CMSIS-RTOS2 and data-cache interface templates supplied by the driver components. |
| [`examples`](https://github.com/ARM-software/CMSIS-Ethos-U/blob/cf13d8d/./examples/Test-Ethos-U/) | CMSIS-Toolbox integration-test solutions for Ethos-U55, Ethos-U65, and Ethos-U85, including Corstone targets, TFLM models, and self-checking tests. |
| [`documentation`](https://github.com/ARM-software/CMSIS-Ethos-U/blob/cf13d8d/./documentation/) | Doxygen sources for the general, Vela, driver, integration, and Zephyr guides, plus generated web content, styles, and authoring guidance. |
| [`overview`](https://github.com/ARM-software/CMSIS-Ethos-U/blob/cf13d8d/./overview/) | Pack overview content and images displayed by CMSIS tooling. |
| [`.github`](https://github.com/ARM-software/CMSIS-Ethos-U/blob/cf13d8d/./.github/) | Workflows that test the example, build the pack, and publish documentation. |
