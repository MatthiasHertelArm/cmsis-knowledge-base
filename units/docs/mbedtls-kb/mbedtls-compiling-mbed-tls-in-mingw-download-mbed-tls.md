Download the latest version of [Mbed TLS](https://github.com/download). You can use a tool like [7-zip](http://www.7-zip.org/) to unzip the file. Unzip to a location like `c:\mingw-64\projects`. This gives you the directory `C:\mingw-64\projects\mbedtls-x.y.z`.
