Specify ECC codes.

The defines can be used in the function ARM_NAND_ReadData and ARM_NAND_WriteData for the parameter **mode**
and in the function ARM_NAND_ExecuteSequence for the parameter **code.**

### ARM_NAND_ECC

```c
ARM_NAND_ECC(n)
```


### ARM_NAND_ECC0

```c
ARM_NAND_ECC0
```


### ARM_NAND_ECC1

```c
ARM_NAND_ECC1
```
