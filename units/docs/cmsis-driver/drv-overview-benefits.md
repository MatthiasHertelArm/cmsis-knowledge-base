Using CMSIS-Driver provides great benefits to the embedded developers and software vendors:

 - The CMSIS-Driver API covers many common peripherals present in modern embedded systems for sensor interaction, data storage, communication and graphics.
 - The unified API follows the similar design principles across all peripherals. This reduces learning efforts and increases developers' productivity. See theoryOperation for details.
 - Driver templates files provide code sceletons that help to get started with implementations for specific peripherals. See cmsis_driver_files.
 - Support for multiple driver instances with AccessStruct.
 - Driver-Validation Suite provides a set of tests to verify compatibility to CMSIS-Driver API definitions.
