Configure and manage the connection to a WiFi access point (AP) or configure and manage the access point (AP).
 The wifi_management_gr functions are used to configure and manage the connection to a WiFi access point (AP)
also called hotspot when in station mode. They are also used to configure and manage the access point (AP) itself
when in access point mode.
