```c
osSafetyWithSameClass
```


Definition for RTOS objects with the same safety class. Can be used as mode argument in the following functions:
 - osThreadSuspendClass :  osThreadSuspendClass
 - osThreadResumeClass :  osThreadResumeClass
 - osKernelDestroyClass :  osKernelDestroyClass
