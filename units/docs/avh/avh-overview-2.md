The **Arm Fixed Virtual Platforms (Arm FVPs)** provide functionally accurate simulation models of Arm-based Cortex-M
CPUs and Corstone-3xx subsystems.

The models are standalone programs that can be executed in a target environment. See Models for a list of FVPs
provided in this context.

Section using gives an overview how to run an embedded program on a target Arm FVP model using command line
interface. [Infrastructure chapter](https://github.com/ARM-software/AVH/blob/bb8431b/DoxyGen/simulation/src/../../infrastructure/html/index.html) provides details on how to obtain Arm FVPs
and use them in various cloud-native or desktop environments workflows, such as GitHub and Keil MDK.
