Once your base configuration is loaded, [Mixins](https://throwtheswitch.github.io/Ceedling/configuration/loading/mixins.md) provide a way
to merge additional YAML configuration into it — for build variants, local
overrides, CI settings, toolchain differences, and more. See the
[Mixins](https://throwtheswitch.github.io/Ceedling/configuration/loading/mixins.md) page for merge rules, loading options, and examples.
