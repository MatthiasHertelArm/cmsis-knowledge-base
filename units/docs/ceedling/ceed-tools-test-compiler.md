Compiler for test & source-under-test code

- `${1}`: Input source
- `${2}`: Output object
- `${3}`: Optional output list
- `${4}`: Optional output dependencies file
- `${5}`: Header file search paths
- `${6}`: Command line #defines

**Default**: `gcc`
