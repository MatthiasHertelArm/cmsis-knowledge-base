Detailed Hardware features for the EK-RA8M1 MCU can be found at EK-RA8M1 - User's Manual


### Supported Features



**Note:** - For using Ethernet module on EK-RA8M1, remove jumper J61 to enable Ethernet B - For using SDHC driver on EK-RA8M1, remove jumper J61 to use with channel 0 - For using I3C driver on EK-RA8M1, install jumper J61 to use with channel 0
