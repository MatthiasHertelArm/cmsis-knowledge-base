Add the ARM::CMSIS-RTX pack to your installation:

```
cpackget add ARM::CMSIS-RTX
```

Alternatively, you can download the latest version from the
[CMSIS-RTX](https://www.keil.arm.com/packs/cmsis-rtx-arm/versions/) page.
