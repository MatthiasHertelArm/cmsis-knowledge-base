```c
__ARM_ARCH_8M_MAIN__
```

 Set to 1 when generating code for Armv8-M Mainline architecture

The **\#define __ARM_ARCH_8M_MAIN__** is set to 1 when generating code for the Armv8-M architecture mainline variant.
This architecture is for example implemented by the Cortex-M33 processor.
