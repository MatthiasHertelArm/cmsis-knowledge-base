```c
__ARM_ARCH_8M_BASE__
```

 Set to 1 when generating code for Armv8-M Baseline architecture

The **\#define __ARM_ARCH_8M_BASE__** is set to 1 when generating code for the Armv8-M architecture baseline variant.
This architecture is for example implemented by the Cortex-M23 processor.
