```c
__ARM_ARCH_7EM__
```

 Set to 1 when generating code for Armv7-M architecture with FPU

The **\#define __ARM_ARCH_7EM__** is set to 1 when generating code for the Armv7-M architecture with floating point extension. This architecture is for example implemented by the Cortex-M4 processor with FPU.
