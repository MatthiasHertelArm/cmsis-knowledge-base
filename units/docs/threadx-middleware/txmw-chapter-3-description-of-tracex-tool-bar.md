The TraceX tool bar provides several buttons to open trace files and control elements of their display.

(figure: Screenshot of the TraceX tool bar.)


**FIGURE 7**

The TraceX tool bar buttons—from left to right—are defined as follows:
                                             
| **Button**                         | **Function** |
| ---------------------------------- | ----------------------------------------------------------------------------------------------- |
| (figure: Open trace file button)      | Open a trace file |
| (figure: Open User Guide button)      | Open this User Guide |
| (figure: Generate execution profile button)       | Generate execution profile |
| (figure:  Generate performance statistics button)       | Generate performance statistics |
| (figure: Generate Thread Stack usage button)       | Generate Thread Stack usage |
| (figure: Display selected event button)       | Display currently selected event |
| (figure: Search button)      | Search for events |
| (figure: Zoom in button)      | Zoom in. |
| (figure: Display zoom button)      | Select percentage of display zoom, where 100% means the entire trace file is displayed within the current view. |
| (figure: Zoom out button)      | Zoom out. |
| (figure: Select first event button)      | Select first event. |
| (figure: Display previous event page button)      | Display previous event page. |
| (figure: Display previous event button)      | Display previous event. |
| (figure: Next/previous navigation button)      | Determine how the next/previous navigation buttons operate. If ***Event*** is selected, navigation is done on the next/previous event. If ***Context*** is selected, navigation is done on the next/previous event on the specified context. If ***Object*** is selected, navigation is done on the next/previous event of the specified object; e.g., events associated with a specific queue. If ***Switches*** is selected, navigation is done on the next/previous change in context. If ***ID*** is selected, navigation is done on the next/previous event of the specified event ID. |
| (figure: Display next event button)      | Display next event. |
| (figure: Display next event page button)      | Display next event page. |
| (figure: Select last event button)      | Select last event. |
