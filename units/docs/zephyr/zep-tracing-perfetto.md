_Part of: Tracing Tools_

Perfetto is a web trace viewer for the Chrome Trace Event Format. It
shows the same scheduling and interrupt activity as TraceCompass without
installing any tool: `scripts/tracing/ctf2perfetto.py` converts a
CTF trace to that format with Python 3 alone::
```
$ZEPHYR_BASE/scripts/tracing/ctf2perfetto.py <trace file> -o trace.json
```
Loading `trace.json` at https://ui.perfetto.dev gives a timeline with one
lane per thread, plus lanes for ISRs and for kernel objects such as semaphores,
mutexes and timers.

The instrumentation subsystem writes the same format from function call
traces, so a build can be looked at either way in the same viewer.

The TSDL `metadata` is read from next to the trace, as babeltrace2 expects,
unless `--metadata` points elsewhere. Use the metadata generated by the build
that produced the trace: CTF records carry no length, so a record the metadata
does not describe cannot be skipped, and the converter stops and names its event
id rather than writing a partial trace.
