Interface functions and configuration parameters for CMSIS-DAP firmware


dap_firmware gives an overview about CMSIS-DAP operation and guides through the steps for enabling the CMSIS-DAP firmware on a custom debug unit.

The configuration file `DAP_config.h` contains the interface functions and configuration parameters that need to be adapted in this process. The subsections in this group list and explain these configurations and functions in details.
