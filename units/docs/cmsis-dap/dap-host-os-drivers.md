Using CMSIS-DAP v2 compliant debug adapter removes the necessity to install separate drivers on Mac OS, Linux, and Windows (8 and above).

dap_config_usb explains how USB stack shall be configured in the CMSIS-DAP firmware to ensure its correct operation with native OS drivers.
