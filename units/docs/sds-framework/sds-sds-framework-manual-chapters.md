- [**Overview**](https://github.com/ARM-software/SDS-Framework/blob/4459441/documentation/overview.md) explains the features of the SDS-Framework and outlines the possibilities.

- [**Theory of Operation**](https://github.com/ARM-software/SDS-Framework/blob/4459441/documentation/theory.md) explains data stream recording and playback.
- [**API Modules**](https://github.com/ARM-software/SDS-Framework/blob/4459441/documentation/SDS_API/modules.md) describes the C interface of the SDS functions that may be used in the target system.
