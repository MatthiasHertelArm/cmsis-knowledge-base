### Tools

- [CMSIS-Toolbox 2.14.0](https://github.com/Open-CMSIS-Pack/cmsis-toolbox/releases) or higher
- Arm Compiler 6.22 or higher
- GCC Compiler 13.2.1 or higher
- CLANG 22.1 or higher
- Arm Virtual Hardware for Corstone-300 v11.26.11 or higher

### Packs

- Required packs are listed in the file [`Hello.csolution.yml`](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/Hello/./Hello.csolution.yml). The file [`Hello.cbuild-pack.yml`](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/Hello/./Hello.cbuild-pack.yml) records the versions that have been used to generate the application.
