To change the device configuration, start STM32CubeMX using the following command.

```bash
> csolution CubeMX.csolution.yml run --generator CubeMX --active MyBoard_ROM@Debug
```

For information about using CubeMX, refer to
[**CMSIS-Toolbox > Configure STM32 Devices with CubeMX**](https://open-cmsis-pack.github.io/cmsis-toolbox/CubeMX/).

The source code generated by CubeMX is imported using the file [STM32CubeMX\`<target-type>`\CubeMX.cgen.yml](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/CubeMX/./STM32CubeMX/MyBoard_ROM/CubeMX.cgen.yml). This allows you to create different settings for each target, for example evaluation board and custom hardware.

> [!NOTE]
> Refer to the [STM32U5xx_DFP pack overview](https://www.keil.arm.com/packs/stm32u5xx_dfp-keil) for information on how to use an IDE workflow with CubeMX.
