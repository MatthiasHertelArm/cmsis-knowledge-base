### Simple

The [Simple](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/Templates/./Simple) template shows the basic structure of a solution containing one project. It is a starting point for a single executable image or library.

### Multicore

The [Multicore](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/Templates/./Multicore) template contains one project for each processor in a multicore device. Target sets group the project images into Debug and Release applications. Select a set with `--active MyTargetName@Debug` or `--active MyTargetName@Release`.

### TrustZone

The [TrustZone](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/Templates/./TrustZone) template separates the secure and non-secure parts into projects and shows how the non-secure project uses the CMSE library generated by the secure project. Target sets group both images into Debug and Release applications. Select a set with `--active MyTargetName@Debug` or `--active MyTargetName@Release`.

### UnitTest

The [UnitTest](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/Templates/./UnitTest) template contains independent test projects that share common support through a reusable layer. It does not use target sets because the projects are separate test executables, typically used in CI. Use `--context .Debug` or `--context .Release` to select all matching test projects.

### ZephyrWest

The [ZephyrWest](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/Templates/./ZephyrWest) template integrates an existing Zephyr application using the West build system. The Zephyr workspace and application remain responsible for their sources and configuration.

### NativeCMake

The [NativeCMake](https://github.com/Open-CMSIS-Pack/csolution-examples/blob/02f71b2/Templates/./NativeCMake) template integrates an existing native CMake project using CMSIS-Toolbox 2.15.0 or higher. The native project remains responsible for its `CMakeLists.txt`, toolchain setup, build targets, and output images.
