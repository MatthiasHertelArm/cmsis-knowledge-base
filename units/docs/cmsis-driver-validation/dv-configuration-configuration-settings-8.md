**Driver_USBD#** selects the driver instance that will be tested.

For example if we want to test `<c>`Driver_USBD2</c> then this setting would be set to `<c>`2</c>.

**Tests** section contains selections of tests to be executed.
For details on tests performed by each test function please refer to USB Device Tests.
