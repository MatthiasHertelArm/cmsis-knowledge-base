## Symptom

`M316`
`%LEVEL% <name> not set.`

## Cause

svdconv prints M316 when a required element or attribute named by <name> is missing from the SVD input, so the device description cannot be fully interpreted. The %LEVEL% placeholder indicates the scope at which the value was expected (for example device or peripheral level). Without the source lines, the exact element is inferred only from the message text.

## Fix

Open the SVD file named in the build output and locate the element or attribute named in the message (the <name> part). Add the missing element at the indicated level with a valid value, then rerun svdconv. If the SVD was generated by a vendor tool, regenerate it with that tool's current export settings.
