You need to run the following initialization command in every new Terminal window:


  **Windows (cmd):**
%USERPROFILE%\.vcpkg\vcpkg-init.cmd
  
  **Windows (PowerShell):**
. ~/.vcpkg/vcpkg-init.ps1
  
  **Linux/macOS:**
. ~/.vcpkg/vcpkg-init
  


Continue by creating your vcpkg configuration file.
