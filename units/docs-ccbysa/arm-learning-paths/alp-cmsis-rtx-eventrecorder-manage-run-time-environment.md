Open the `Manage run-time environment` dialog, and enable `CMSIS-View` > `Event Recorder` (`DAP` variant).

Enable `CMSIS-Compiler` > `STDOUT (API)`, and set to `Event recorder`. You'll also need to enable `CMSIS-Compiler` > `Core`.

Click `OK` to save.
