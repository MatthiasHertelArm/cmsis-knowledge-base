Learn how to import and build example projects in Arm Development Studio and debug embedded applications using Fixed Virtual Platforms (FVPs) or hardware with DSTREAM debug probes.

**Who is this for:** This is an introductory topic for embedded software developers new to Arm Development Studio.

**Learning objectives:**

- Import and build an example project
- Debug the example code running on a Fixed Virtual Platform (FVP)
- Debug the example code running on a board with a DSTREAM debug probe

**Prerequisites:** Some familiarity with embedded programming is assumed

**Steps:**

1. Import and build example project
2. Debug the example
3. Other compilers and project types

Time: about 30 minutes.
