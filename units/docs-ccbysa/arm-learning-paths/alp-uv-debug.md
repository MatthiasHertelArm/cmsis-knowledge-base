Learn how to debug microcontrollers using µVision with basic run/stop debug, advanced techniques using Event Recorder and Serial Wire Viewer, ETM Trace for performance analysis, and power measurement with ULINKplus.

**Who is this for:** This is an advanced topic for software developers who want to debug microcontrollers using µVision.


**Learning objectives:**

- Use basic run/stop debug
- Learn advanced debug techniques using Event Recorder and Serial Wire Viewer
- Learn to use ETM Trace for optimum performance
- Measure your power consumption with ULINKplus

**Prerequisites:**

- Some familiarity with embedded programming is assumed
- An [Arm Account](https://developer.arm.com/register) is required
- A Windows machine
- Installation of [Arm Keil MDK](https://learn.arm.com/install-guides/mdk/) with an active MDK-Community license
- Installation of the [Corstone-300 Ecosystem FVP](https://learn.arm.com/install-guides/fm_fvp/eco_fvp/)

**Steps:**

1. Use basic run/stop debug
2. Debug using Event Recorder
3. Debug using Serial Wire Viewer
4. Advanced debug with ETM trace
5. Measure Power with ULINKplus

Time: about 90 minutes.
