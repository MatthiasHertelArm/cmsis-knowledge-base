Run the script to start the container:


  **macOS and Linux:**
./start-dev.sh
  
  **Windows (PowerShell):**
.\start-dev.ps1
  


You'll see the following command prompt:

```output
developer@container_ID:~$
```

You're now inside the Docker container.
