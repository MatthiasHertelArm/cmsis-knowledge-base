Zephyr SDK is available on Windows, Linux, and macOS hosts. However the FVP is natively available for Windows and Linux hosts, and can be run on macOS with a Docker as explained in [AVH FVPs on macOS](https://learn.arm.com/install-guides/fvps-on-macos/).

These instructions assume an Ubuntu Linux host machine.
