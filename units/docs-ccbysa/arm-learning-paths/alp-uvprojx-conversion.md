Learn how to import, convert, and build uvprojx-based projects to csolution format using Keil Studio, µVision, and command-line tools for CMSIS-Toolbox compatibility.

**Who is this for:** This is a topic for users of µVision who want to migrate to the new project format (csolution) required by CMSIS-Toolbox.

**Learning objectives:**

- Import, convert, and build uvprojx-based projects in Keil Studio.
- Convert uvprojx-based projects in µVision.
- Convert and build uvprojx-based projects on the command line.

**Prerequisites:**

- Install [Keil Studio](https://learn.arm.com/install-guides/keilstudio_vs/) on your machine.
- Install [µVision](https://learn.arm.com/install-guides/mdk/) on your machine.
- The &micro;Vision project must use Arm Compiler 6 as the default toolchain. Arm Compiler 5 is not supported.

**Steps:**

1. Using Keil Studio
2. Using µVision
3. Using the command line

Time: about 10 minutes.
