Learn how to migrate CMSIS v5 projects to CMSIS v6 by identifying supported toolchains, installing required CMSIS-Packs, and selecting the necessary software components.

**Who is this for:** This is an advanced topic for embedded developers who want to migrate their projects to CMSIS v6.

**Learning objectives:**

- Identify the supported toolchains.
- Install the required CMSIS-Packs.
- Select the software components needed to migrate your projects to CMSIS v6.

**Prerequisites:**

- A CMSIS v5 based project.
- A basic understanding of the CMSIS-Pack system.

**Steps:**

1. Supported toolchains
2. Required CMSIS-Packs
3. Device mapping
4. Project format conversion
5. Troubleshooting

Time: about 10 minutes.
