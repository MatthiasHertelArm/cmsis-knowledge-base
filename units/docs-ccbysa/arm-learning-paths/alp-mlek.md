Learn how to build examples from the Machine Learning Evaluation Kit (MLEK) and run them on the Arm Ecosystem FVP for machine learning application development on microcontrollers.

**Who is this for:** This is an introductory topic for embedded software developers interested in machine learning applications.

**Learning objectives:**

- Build examples from the Arm Machine Learning Evaluation Kit (MLEK)
- Run the examples on Arm Ecosystem Fixed Virtual Platform (FVP)

**Prerequisites:**

- Some familiarity with embedded programming
- A Linux host machine running Ubuntu

**Steps:**

1. Build the ML Evaluation Kit examples
2. Install Arm Ecosystem FVP
3. Run the examples on the FVP

Time: about 30 minutes.
