### New C source file

Right-click `Source Group 1` and select `Add New Item`. Select `C file (.c)`.

### Build

Save all files, and click the `Build` button (`F7`).

### Debug

Click the `Debug` button (`Ctrl+F5`) to load the example to the FVP. The code will stop at `main()`.
