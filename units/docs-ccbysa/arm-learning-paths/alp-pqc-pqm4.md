Learn how to implement and test post-quantum cryptographic algorithms on Arm Cortex-M4 microcontrollers using the pqm4 library.

**Who is this for:** This is an advanced topic for software developers and cryptography enthusiasts interested in implementing and testing post-quantum cryptographic algorithms on Arm Cortex-M4 microcontrollers.

**Learning objectives:**

- Describe the design goals and supported algorithms of the pqm4 library.
- Set up the development environment for Arm Cortex-M4.
- Implement and test post-quantum cryptographic algorithms.
- Benchmark and profile cryptographic implementations.
- Integrate new cryptographic schemes into the pqm4 framework.

**Prerequisites:**

- Computer with Python 3.8 or higher
- Arm GNU Toolchain [installed](https://learn.arm.com/install-guides/gcc/arm-gnu/)
- An Arm Cortex-M4 development board such as NUCLEO-L4R5ZI, NUCLEO-L476RG, or STM32F4 Discovery, with stlink or OpenOCD for flashing. Alternatively, install QEMU to simulate the hardware without a physical board.

**Steps:**

1. Understand pqm4 and post-quantum cryptography
2. Set up the pqm4 development environment
3. Run pqm4 tests and benchmarks
4. Add a KEM implementation to pqm4

Time: about 120 minutes.
