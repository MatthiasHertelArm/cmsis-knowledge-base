Port Zephyr RTOS to the Arm Corstone-320 MPS4 FPGA platform by creating board support files and device tree configuration, then build and run a hello_world sample on the physical board.

**Who is this for:** This is an introductory topic for embedded developers who want to port Zephyr RTOS to the Arm Corstone-320 MPS4 FPGA platform.

**Learning objectives:**

- Set up the Zephyr build environment and Arm GNU Toolchain for Corstone-320 MPS4 development
- Create board support files, including device tree, Kconfig, and board metadata, to port Zephyr to the Corstone-320 MPS4 FPGA platform
- Build and run the hello_world sample on the Corstone-320 MPS4 board to validate the port

**Prerequisites:**

- Basic familiarity with embedded C programming
- Basic knowledge of Zephyr RTOS
- A Corstone-320 MPS4 FPGA development board
- A Linux development environment, for example Ubuntu 22.04 or later
- Git and Python

**Steps:**

1. Set up the Zephyr build environment
2. Add Zephyr board support for the Arm Corstone-320 MPS4 platform
3. Build and run the hello_world sample on Arm Corstone-320 MPS4

Time: about 45 minutes.
