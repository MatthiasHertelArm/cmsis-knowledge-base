Launch the Arm Virtual Hardware AMI in your AWS account. For full instructions refer to the [Arm Virtual Hardware install guide](https://learn.arm.com/install-guides/avh/#corstone).

The example used here makes use of the [Tkinter](https://docs.python.org/3/library/tkinter.html) Python interface to Tcl/Tk, and can be installed in the AVH terminal with:
```console
sudo apt install -y python3-tk
```
