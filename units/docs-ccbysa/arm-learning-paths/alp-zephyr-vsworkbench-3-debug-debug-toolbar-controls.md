The debug toolbar provides the following controls for stepping through your code:

- **Continue/Pause (F5)**
- **Step Over (F10)**
- **Step Into (F11)**
- **Step Out (Shift+F11)**
- **Restart (Ctrl+Shift+F5)**
- **Stop (Shift+F5)**
