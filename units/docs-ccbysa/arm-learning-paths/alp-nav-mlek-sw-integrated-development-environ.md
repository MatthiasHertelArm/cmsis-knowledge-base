Use the [Arm Development Studio install guide](https://learn.arm.com/install-guides/armds/) to set up Arm DS on Linux or Windows. 

[Keil MDK](https://learn.arm.com/install-guides/mdk/) is a popular microcontroller development toolkit on Windows.

Both IDEs contain `Arm Compiler for Embedded` to build applications, and can connect to the Ecosystem FVPs for software debug and test.
