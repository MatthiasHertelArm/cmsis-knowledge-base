Build a letter recognition neural network model using TensorFlow and deploy it on an STM32 B-L475E-IOT01A2 board.

**Who is this for:** This is an advanced topic for software developers interested in building network models for microcontrollers.

**Learning objectives:**

- Build a letter recognition neural network(NN) model using TensorFlow framework
- Run the NN model on an STM32 B-L475E-IOT01A2 board using STM32CubeAI

**Prerequisites:**

- Familiarity with ML concepts
- Familiarity with C programming on microcontrollers
- STM32 B-L475E-IOT01A2 board

**Steps:**

1. Prepare development environment
2. Collect training data
3. Train the model
4. Feature extraction
5. Run the model on development board

Time: about 60 minutes.
