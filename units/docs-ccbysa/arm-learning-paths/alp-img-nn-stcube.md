Develop a image classification neural network model and deploy it on an STM32 B-L475E-IOT01A2 board.

**Who is this for:** This is an advanced topic for embedded software developers interested in building neural network models for microcontrollers.

**Learning objectives:**

- Build a convolution neural network(CNN) model for image classification.
- Run the CNN model on an STM32 B-L475E-IOT01A2 board using STM Cube AI

**Prerequisites:**

- Familiarity with ML concepts
- Familiarity with C programming on microcontrollers
- STM32 B-L475E-IOT01A2 board

**Steps:**

1. Prepare environment
2. Build an image classification NN model trained with the CIFAR-10 dataset
3. Deploy the image classification NN model on STM32
4. Run the image classification NN model on STM32

Time: about 60 minutes.
