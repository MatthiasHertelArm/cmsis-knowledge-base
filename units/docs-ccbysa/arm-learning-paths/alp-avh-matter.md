Learn how to build Matter reference examples on Arm Virtual Hardware, demonstrate device communication, and automate testing with GitHub Actions CI/CD workflows.

**Who is this for:** This is an introductory topic for embedded software developers new to Arm Virtual Hardware.

**Learning objectives:**

- Instantiate Arm Virtual Hardware instances
- Build and run Matter examples on Arm Virtual Hardware
- Demonstrate communication between two virtual hardware targets
- Use GitHub Actions to manage ongoing development in a CI/CD workflow

**Prerequisites:** Some familiarity with embedded programming is assumed

**Steps:**

1. Prepare AVH instances of Raspberry Pi 4
2. Build and run Matter examples on Arm Virtual Hardware
3. Manage development in a CI/CD workflow with Self-Hosted Runner
4. Control Arm Virtual Hardware with API

Time: about 60 minutes.
