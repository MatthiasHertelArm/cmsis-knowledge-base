Learn how to create, build, and debug an RTX5 RTOS-based application using Keil μVision with CMSIS-RTOS2 API and Event Recorder for embedded Cortex-M development.

**Who is this for:** This is an introductory topic for software developers new to RTOS development.

**Learning objectives:** Implement a basic RTOS-based application

**Prerequisites:**

- An installation of [Arm Keil MDK](https://learn.arm.com/install-guides/mdk/) or [Arm Development Studio](https://learn.arm.com/install-guides/armds/) (MDK recommended)
- Some familiarity with CMSIS is assumed

**Steps:**

1. Create and setup Keil MDK project
2. Initialize the operating system
3. Create RTOS threads
4. Build and run the application
5. Using Event Recorder

Time: about 30 minutes.
