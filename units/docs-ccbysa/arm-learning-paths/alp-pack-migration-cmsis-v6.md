Learn how to migrate a CMSIS v5-based CMSIS-Pack with device support to CMSIS v6 and update example projects for compatibility with the new CMSIS version.

**Who is this for:** This is an advanced topic for maintainers of CMSIS-Packs with device support.

**Learning objectives:**

- Migrate a CMSIS v5-based CMSIS-Pack with device support to CMSIS v6.
- Update example projects.

**Prerequisites:**

- A good understanding of [CMSIS-Packs](https://open-cmsis-pack.github.io/Open-CMSIS-Pack-Spec/main/html/index.html).
- A CMSIS-Pack that contains device support and was created for CMSIS v5.

**Steps:**

1. Device support
2. Example projects

Time: about 10 minutes.
