Learn how to build and run Zephyr RTOS applications on the Arm Corstone-300 Fixed Virtual Platform using Arm Virtual Hardware.

**Who is this for:** This is an introductory topic for software developers getting started with the Zephyr RTOS.

**Learning objectives:** Build and run Zephyr applications on the Corstone-300

**Prerequisites:**

- Some familiarity with embedded C programming
- A Linux machine running Ubuntu, or an AWS account to use [Arm Virtual Hardware](https://www.arm.com/products/development-tools/simulation/virtual-hardware)

**Steps:**

1. Build and run Zephyr applications

Time: about 30 minutes.
