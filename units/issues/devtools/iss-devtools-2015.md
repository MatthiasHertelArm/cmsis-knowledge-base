## Cause

The failing file was generated by CMSIS-Toolbox 2.7.0, which wrote the short component version that the newer schema does not accept; 2.8.0 normalises it.

## Fix

Regenerate the cbuild*.yml files with CMSIS-Toolbox 2.8 or later (delete the stale generated files and run setup again).
