## Cause

The rejected *.cbuild.yml had been generated by CMSIS-Toolbox 2.7.0, whose problem was fixed in 2.8.0; it was not a schema defect.

## Fix

Update to CMSIS-Toolbox 2.8.0 or later so that the cbuild files are generated by the new version.
