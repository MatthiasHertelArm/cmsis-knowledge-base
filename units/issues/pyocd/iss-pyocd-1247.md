## Symptom

`ModuleNotFoundError: No module named 'pyocd._version`

## Cause

pyocd._version is generated by setuptools_scm at build time, which setup.py does not install by itself.

## Fix

Install with 'pip install .' or install setuptools_scm[toml] first.
