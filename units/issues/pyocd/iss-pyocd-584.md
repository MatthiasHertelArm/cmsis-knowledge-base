## Symptom

`ModuleNotFoundError: No module named 'pyocd._version'`

## Cause

The version module is generated by setuptools_scm at install time. Running from an unpacked source tree without installing never creates it.

## Fix

Create a virtualenv and run `pip install -r dev-requirements.txt` in the repository root, which installs pyOCD in editable mode and generates the file.
